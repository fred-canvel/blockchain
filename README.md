# Blockchain Blog

A modern, high-performance blockchain blog built with React and Vanilla CSS.

## Features

- **Modern UI/UX**: Glassmorphism, neon accents, and smooth animations.
- **Responsive Design**: Fully responsive for all devices.
- **Performance**: Optimized with Vite.
- **No Framework Dependencies**: Styled purely with Vanilla CSS for maximum control.

## Getting Started

1.  Install dependencies:
    ```bash
    npm install
    ```

2.  Run the development server:
    ```bash
    npm run dev
    ```

3.  Open [http://localhost:5173](http://localhost:5173) in your browser.
